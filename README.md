# RNN Sentiment Analysis — IMDB Movie Reviews

Week 6 · Task 1 — Recurrent Neural Networks (RNNs) for Sequence Data

## Dataset

**IMDB Movie Reviews** (built into `tensorflow.keras.datasets.imdb`): 50,000
labeled reviews (25k train / 25k test), balanced between positive and
negative sentiment. Reviews are already integer-encoded by word frequency
rank, which keeps the preprocessing focused on **vocabulary capping** and
**sequence padding** rather than raw text cleaning.

| | |
|---|---|
| Task | Binary sentiment classification (positive / negative) |
| Vocabulary size | 10,000 most frequent words |
| Sequence length | Padded/truncated to 200 tokens |
| Train / Val / Test | 22,500 / 2,500 / 25,000 |

## Model Architecture

```
Input(200,)
  -> Embedding(10000, 64)
  -> LSTM(64)              # or SimpleRNN(64) / GRU(64) for comparison
  -> Dropout(0.3)
  -> Dense(1, sigmoid)
```

- **Embedding layer**: learns a dense 64-dim vector per word instead of a
  10,000-dim one-hot vector.
- **Recurrent layer**: processes the sequence one token at a time, carrying
  a hidden state forward. LSTM/GRU add gating mechanisms (forget/input/
  update gates) that let gradients flow across long sequences without
  vanishing — the key advantage over a plain `SimpleRNN`.
- **Dropout + sigmoid head**: regularizes and produces a single
  positive-sentiment probability.

## How to Run

```bash
pip install -r requirements.txt

# preprocess + cache data
python src/preprocess.py

# train a single model
python src/rnn_model.py --cell lstm --epochs 10

# train and compare all three cell types
python src/rnn_model.py --compare --epochs 10
```

Outputs (`*_training_history.png`, `cell_comparison_f1.png`) are written to
`assets/`.
